## Project Overview

This project is the Phase 3 website development for **Pawsitive Pet Academy**, a Durban-based pet care education and practical animal training business.

The website is being developed to provide customers with information about the academy, its services and courses, while also allowing potential customers to make enquiries and find contact information.

Phase 3 focuses on creating the website using **HTML only**. CSS styling and JavaScript functionality are not included in this phase.

## Organisation

**Organisation:** Pawsitive Pet Academy
**Location:** Durban, KwaZulu-Natal, South Africa
**Founder:** Sarah Smith
**Established:** 2023
**Industry:** Pet Care Education and Animal Training

## Purpose of the Website

The purpose of the website is to create an online presence for Pawsitive Pet Academy where users can:

* Learn about the organisation.
* View the services and training courses offered.
* Find information about the academy.
* Make an enquiry.
* Find the academy's contact information.
* Navigate between the different website pages easily.

## Technologies Used

The following technologies and tools are used during this phase:

* **HTML5** — Used to create the structure and content of the website.
* **Visual Studio Code** — Used as the code editor.
* **Git** — Used for version control.
* **GitHub** — Used to store and manage the project repository.
* **Web Browser** — Used to test and view the website.

### Important Note

**CSS and JavaScript are not used in Phase 3.**

The main focus is on creating a correct and functional HTML website structure before styling and additional functionality are added in later phases.

## Website Pages

The website contains the following main pages:

### 1. Home Page — `index.html`

The Home page introduces visitors to Pawsitive Pet Academy.

It includes:

* Academy name and logo.
* Welcome message.
* Short introduction to the organisation.
* Information about pet care and training.
* Navigation links to the other pages.
* Call-to-action information encouraging users to learn more.

### 2. About Us — `about.html`

The About Us page provides information about Pawsitive Pet Academy.

It includes:

* Background of the organisation.
* Information about the founder.
* The purpose of the academy.
* Information about its approach to pet care and training.
* Mission and values.

### 3. Services / Courses — `services.html`

This page provides information about the services and courses offered by Pawsitive Pet Academy.

It includes:

* Available training courses.
* Course descriptions.
* Course information.
* Course pricing where applicable.
* Information about course discounts.

The discount structure is:

* 1 course — No discount.
* 2 courses — 5% discount.
* 3 courses — 10% discount.
* 4 or more courses — 15% discount.

### 4. Enquiry — `enquiry.html`

The Enquiry page allows users to submit an enquiry to Pawsitive Pet Academy.

The page includes an HTML form with fields such as:

* Name.
* Surname.
* Email address.
* Contact number.
* Enquiry type.
* Message.
* Submit button.

The form is intended to provide a structured way for potential customers to request more information.

### 5. Contact Us — `contact.html`

The Contact Us page provides information that allows customers to contact and locate Pawsitive Pet Academy.

It includes:

* Contact details.
* Email address.
* Telephone information.
* Business location information.
* Map/location information.
* Contact form information where required.

## Website Navigation

The website uses HTML hyperlinks to allow users to move between the pages.

The main navigation structure is:

```text
Home
 ├── About Us
 ├── Services / Courses
 ├── Enquiry
 └── Contact Us
```

Each page contains navigation links so that users can move between the main sections of the website.

## HTML Structure

The website uses appropriate HTML5 elements to organise the content.

Examples include:

* `<header>` — Website header.
* `<nav>` — Navigation menu.
* `<main>` — Main page content.
* `<section>` — Content sections.
* `<article>` — Independent content.
* `<footer>` — Footer information.
* `<h1>` to `<h6>` — Headings.
* `<p>` — Paragraphs.
* `<img>` — Images.
* `<a>` — Hyperlinks.
* `<ul>` and `<ol>` — Lists.
* `<form>` — Forms.
* `<input>` — Form input fields.
* `<label>` — Form labels.
* `<button>` — Buttons.

Semantic HTML is used where appropriate to make the structure of the website clear and organised.
